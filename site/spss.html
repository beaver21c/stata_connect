시작하기

고른 방법의 탭을 누르면 해당 순서가 보임.

  1. Claude 데스크톱 앱 설치·로그인

    claude.com/download에서 Windows용 앱을 받아 설치하고 Pro 이상 계정으로 로그인.

  2. 파일 생성 기능 켜기
    Settings›Capabilities›Create and edit files켜기

    스킬을 쓰려면 필요함(Claude 공식 안내). 앱 버전에 따라 “Code execution and file creation”으로 보일 수 있음.

  3. SPSS 분석 스킬 추가(플러그인)
    Customize›Plugins›Add›Add marketplace

    주소 칸에 beaver21c/stata_connect 입력 → 목록의 spss-agent 추가.

  4. SPSS 연결 확장 설치

    다운로드의 {{SPSS_MCPB_FILE}}을 받아 더블클릭 → Claude 앱 설치 화면에서 설치. SPSS를 자동으로 못 찾을 때만 설정 칸에 SPSS 설치 폴더(stats.exe가 있는 폴더)를 지정.

    더블클릭으로 열리지 않으면: Settings › Extensions › Advanced settings › Install Extension…에서 파일 선택(MCPB 공식 안내).

  5. 새 채팅에 “SPSS 연결 점검해줘” 입력

    점검표가 모두 통과로 나오면 준비 끝 → 첫 분석으로. T1이 “동봉 Python 없음”이면 아래 자주 묻는 질문 참조.

  1. Claude 데스크톱 앱 설치·로그인 → Code 탭

    claude.com/download에서 설치하고 Pro 이상 계정으로 로그인한 뒤 위쪽의 Code 탭을 누름. 관리자 권한·Git 설치는 필요 없음(Claude Code 공식 안내).

  2. SPSS 분석 스킬 추가(플러그인)
    Customize›Plugins›Add›Add marketplace

    beaver21c/stata_connect 입력 → spss-agent 추가.

    터미널판 Claude Code: /plugin marketplace add beaver21c/stata_connect → /plugin install spss-agent@stata-connect

  3. 분석 폴더 열기

    새 세션의 작업 폴더로 빈 폴더를 고름(예: 문서\SpssAgent\프로젝트1). 문서·바탕화면 전체를 고르지 않음.

  4. /spss-agent:setup 입력

    Claude가 설치 파일 받기 → 확인값 대조 → SPSS·동봉 Python 확인 → 폴더 준비 → 연결 등록을 차례로 진행하며 명령마다 승인을 요청함. 명령 내용을 읽고 “허용”.

    같은 폴더로 새 세션을 열고, spss 서버 사용을 묻는 창에서 허용. 이후 첫 분석으로.

자료 보호 원칙

AI가 실수로라도 원자료를 보지 않도록 설계함. 원칙은 Stata판과 같음.

계산은 SPSS가AI는 수치를 직접 계산하지 않고, 출력에 나온 값만 인용함.
원자료는 AI로 보내지 않음자료 구조는 변수 이름·라벨·결측 수만 확인.
실행 전 연구자 승인문법을 실행하거나 파일을 바꾸는 작업은 매번 승인 창이 뜸.
항상 재현 가능모든 분석이 .sps로 남아 새 SPSS에서 다시 실행해 결과를 대조함.

차단되는 것과 보내지는 것

  • 차단: 사례 값 출력(LIST·PRINT·목록형 SUMMARIZE), 운영체제 명령(HOST), 파일 삭제(ERASE), Python·R 코드 실행(BEGIN PROGRAM), 프로젝트 폴더 밖으로 저장, 원자료 폴더(data) 덮어쓰기.
  • 확인 후 실행: 고유값이 대부분인 변수(아이디 등)의 빈도표·집단별 요약, 자료 파일 내보내기 등은 이유를 설명하고 연구자 동의를 받은 뒤에만 실행.
  • AI로 보내지는 것: 요약통계, 검정 결과, 변수 이름·라벨 같은 자료 구조 정보.

이 장치는 사고를 막기 위한 안전장치이며 완전한 보안 장치는 아님. 행정자료·민감자료는 기관의 반출 기준과 승인 절차를 함께 따를 것.

자주 묻는 질문

SPSS 창이 안 뜨는데 정상인가요?

정상임. SPSS를 화면 없이 실행하는 방식이라 창이 뜨지 않음. 결과는 프로젝트의 output/logs 폴더에 남고, 같은 .sps 파일을 SPSS에서 직접 열어 실행해 볼 수 있음.

어느 SPSS 버전까지 되나요?

SPSS Statistics 22 이상을 대상으로 함. 22·23은 SPSS에 들어 있는 Python 2.7, 24~26은 3.4(없으면 2.7), 27부터는 3.x를 사용하도록 만들었고, Python 2.7·3.4에서의 동작은 자동 시험(가짜 SPSS)으로만 확인함. 실제 SPSS에서의 버전별 시험은 진행 전.

점검에서 “동봉 Python 없음”이 나와요

SPSS를 설치할 때 Python Essentials(Integration Plug-in for Python)가 빠졌을 가능성이 있음. SPSS 설치 프로그램에서 해당 구성요소를 추가하거나, 기관 전산 담당자에게 요청. Python이 다른 위치에 있으면 확장 설정의 “SPSS 동봉 Python” 칸에 python.exe를 지정.

Word로 받은 표가 .doc로 저장됐어요

SPSS 27 이하는 Word 내보내기를 Word 97-2003(.doc) 형식으로 저장함(IBM 문서 기준, 2차 확인). 도구가 자동으로 .doc로 바꿔 저장하며, 최신 Word에서 그대로 열림.

“시험판”은 무슨 뜻인가요?

설치 파일은 저장소의 자동 점검(Windows에서 빌드 후 SPSS 없이 연결·도구 목록·차단 규칙 시험, 가짜 SPSS로 문법 실행까지)을 통과했지만, 실제 SPSS와 Claude·Codex 앱에서의 시험은 아직 진행 전이라는 뜻.

설치할 때 “Windows의 PC 보호” 파란 창이 뜨면?

시험판은 코드 서명 인증서가 없어 이 창이 뜰 수 있음. 이 페이지에서 받은 파일인지(필요하면 확인값 대조) 확인한 뒤 “추가 정보 → 실행”을 누름. 기관 PC에서는 보안 프로그램이 막을 수 있으므로 전산 담당자에게 예외 등록을 요청.

“차단됨”이라는 메시지가 나왔어요

사례 값이 AI로 넘어갈 수 있는 명령이 막힌 것임. AI가 요약통계 등 다른 방법으로 바꿔 제안함. 꼭 사례를 봐야 하면 연구자가 SPSS에서 직접 실행.

오래 걸리는 분석은?

요청 하나당 기본 15분(900초) 제한이 있음. 넘으면 SPSS가 종료되고 열어 둔 자료가 사라지므로, 자료 불러오기부터 다시 실행함.

구조방정식(SEM)도 되나요?

SPSS Statistics 본체에는 구조방정식 명령이 없고 AMOS 등 별도 제품이 필요한 것으로 알려져 있음. 이 도구는 현재 SPSS Statistics 문법만 다룸.

라이선스 관련 주의할 점이 있나요?

“다시 실행해 결과 대조” 기능은 SPSS를 하나 더 띄움. 기관 라이선스가 동시 실행을 제한하면 이 기능이 실패할 수 있음(실제 시험 전).

오류 알리기

연결 점검에서 만들어진 점검 보고서 파일만 첨부해 오류 알리기에 올림. 분석 출력 원문, 자료 파일 경로, 변수 값은 올리지 않음.
