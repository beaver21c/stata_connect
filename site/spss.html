작동 방식

AI는 문법 작성과 출력 판독만 하고, 모든 통계량은 SPSS가 계산함.

채팅으로 요청연구자
“성별에 따른 만족도 차이를 t검정해줘”
문법 작성AI
.sps 파일에 섹션 단위로 SPSS 문법 작성
승인 후 계산연구자 → SPSS
승인하면 내 PC의 SPSS가 화면 없이 실행
검증·해석AI
출력을 읽고 가정 위배를 점검, 수정안·해석 제시
  • SPSS 창은 뜨지 않음 — 결과는 출력 파일(output/logs)로 남고, AI가 읽어서 설명함.
  • 같은 .sps 파일을 연구자가 SPSS에서 직접 열어 실행해 볼 수 있음.

개별 사례 값(자료의 행)은 AI로 보내지 않음. 요약통계·검정 결과만 전달됨 → 자료 보호 원칙

연결 점검

문제가 생기면 채팅에 “SPSS 연결 점검해줘”라고 입력. 문법 안에서 만든 예제 숫자(1~10)만 쓰며 내 자료는 쓰지 않음.

항목무엇을 확인하나
T1SPSS 설치와 Python 연동 기능
T2AI가 SPSS를 화면 없이 띄울 수 있는지
T3앞서 만든 자료가 다음 요청에서도 유지되는지
T4계산 결과가 기준값과 일치하는지
T5AI가 출력 파일을 제대로 받는지
T6사례 값을 보여 주는 명령이 차단되는지
T7문법 파일 섹션 편집이 제대로 되는지
T8파일을 저장할 수 있는지
T9새로 띄운 SPSS에서 다시 돌려도 결과가 같은지
T10최신 버전인지

점검이 끝나면 문서\StataAgent\점검보고서_날짜.html이 만들어짐. 자료 경로·변수명·출력 원문은 들어가지 않음.

자료 보호 원칙

AI가 실수로라도 원자료를 보지 않도록 설계함. 원칙은 Stata판과 같음.

계산은 SPSS가AI는 수치를 직접 계산하지 않고, 출력에 나온 값만 인용함.
원자료는 AI로 보내지 않음자료 구조는 변수 이름·라벨·결측 수만 확인.
실행 전 연구자 승인문법을 실행하거나 파일을 바꾸는 작업은 매번 승인 창이 뜸.
항상 재현 가능모든 분석이 .sps로 남아 새 SPSS에서 다시 실행해 결과를 대조함.

차단되는 것과 보내지는 것

  • 차단: 사례 값 출력(LIST·PRINT·목록형 SUMMARIZE), 운영체제 명령(HOST), 파일 삭제(ERASE), Python·R 코드 실행(BEGIN PROGRAM), 프로젝트 폴더 밖으로 저장, 원자료 폴더(data) 덮어쓰기.
  • 확인 후 실행: 고유값이 대부분인 변수(아이디 등)의 빈도표·집단별 요약, 자료 파일 내보내기 등은 이유를 설명하고 연구자 동의를 받은 뒤에만 실행.
  • AI로 보내지는 것: 요약통계, 검정 결과, 변수 이름·라벨 같은 자료 구조 정보.

이 장치는 사고를 막기 위한 안전장치이며 완전한 보안 장치는 아님. 행정자료·민감자료는 기관의 반출 기준과 승인 절차를 함께 따를 것.

자주 묻는 질문

SPSS 창이 안 뜨는데 정상인가요?

정상임. SPSS를 화면 없이 실행하는 방식이라 창이 뜨지 않음. 결과는 프로젝트의 output/logs 폴더에 남고, 같은 .sps 파일을 SPSS에서 직접 열어 실행해 볼 수 있음.

설치 프로그램은 언제 나오나요?

실제 SPSS와 Claude·Codex 앱에서 연결 시험을 마친 뒤 공개함. 공개되면 이 페이지의 다운로드 칸에 버튼이 생김.

“차단됨”이라는 메시지가 나왔어요

사례 값이 AI로 넘어갈 수 있는 명령이 막힌 것임. AI가 요약통계 등 다른 방법으로 바꿔 제안함. 꼭 사례를 봐야 하면 연구자가 SPSS에서 직접 실행.

오래 걸리는 분석은?

요청 하나당 기본 15분(900초) 제한이 있음. 넘으면 SPSS가 종료되고 열어 둔 자료가 사라지므로, 자료 불러오기부터 다시 실행함.

구조방정식(SEM)도 되나요?

SPSS Statistics 본체에는 구조방정식 명령이 없고 AMOS 등 별도 제품이 필요한 것으로 알려져 있음. 이 도구는 현재 SPSS Statistics 문법만 다룸.

라이선스 관련 주의할 점이 있나요?

“다시 실행해 결과 대조” 기능은 SPSS를 하나 더 띄움. 기관 라이선스가 동시 실행을 제한하면 이 기능이 실패할 수 있음(실제 시험 전).

오류 알리기

연결 점검에서 만들어진 점검 보고서 파일만 첨부해 오류 알리기에 올림. 분석 출력 원문, 자료 파일 경로, 변수 값은 올리지 않음.
